# Employee-Manager
A Database System subject mini project.
Features:
- CRUD: Add new employee, display all employees, update employee's data, and delete employee.
- Display an employee details (card).
- Employee presence.
- Admin/Employee users.
- Login with password.

# Programming Language
We are using Python with Flask for back-end, and MySQL (Laragon) for database system.

# Flask Installation
```bash
pip install Flask
pip install flask-mysqldb
```
